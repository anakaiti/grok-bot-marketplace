# First read

Aim to finish in about a minute.

1. **Fetch** the page as text first (WebFetch, not the browser). Capture the text in order: headline, subhead, first CTA, then the rest. If possible take a screenshot of the first screen at desktop and mobile width, but only after the text read, within about 60 seconds, and never retry a browser that hangs; skip the screenshot and say so.
2. **Five-second test**: using only the headline, subhead, and first button, write what a stranger would say back: "This is a ___ for ___ that lets you ___." If you can't fill a blank, that blank is the top issue.
3. **Scroll test**: note where the page first answers what it is, who it's for, what it costs (or how to find out), and why to trust it. Record the section number for each, or "never".
4. **Friction**: jargon a buyer wouldn't use, claims with no proof, more than one competing primary CTA, buttons that say "Learn more" or "Submit", broken or slow sections.

Return the stranger summary, the four answers with locations, and a quoted list of friction lines. Don't rewrite yet.
