# Copy rewrite

Rules:
- Fix the top issue from copy-critic-clarity-score first. At most three rewrites per page per run.
- For a headline: give three options. One plain (says exactly what it does), one outcome-led (what the buyer gets), one buyer-led (names who it's for). Each under 10 words.
- For a CTA: a specific verb plus the thing ("Book a 15-minute demo", not "Get started"). One primary CTA only.
- Keep claims true to the current page and setup.md. No new features, stats, logos, or quotes. Respect the never-use list.
- No em dashes.

Output for each: the current line (quoted), the suggested line, and one sentence on why. If Drive is connected and the owner wants it, put them in a doc and share the link. Never edit the live site or open a pull request without a yes; if the owner wants the change shipped, write a short spec they can hand to a developer or coding agent.

Log the suggestions in reviews.md and record the owner's decision when they give it.
