- **What**: can a stranger say what the product does from the first screen? 10 = one plain sentence, 0 = pure slogan.
- **Who**: is the buyer named or obvious? 10 = they'd recognize themselves, 0 = "for everyone".
- **Next**: is there one obvious action that matches setup.md? 10 = one clear button with a specific verb, 0 = no CTA above the fold or several fighting.

For each score, quote the line that earned it. Name the single lowest score as the top issue.
